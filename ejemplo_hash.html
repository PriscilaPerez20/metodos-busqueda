Implementación de Búsqueda Hash en C#

Código fuente de ejemplo

A continuación se muestra un ejemplo práctico en C# utilizando la clase Dictionary<TKey, TValue>, la cual implementa internamente una tabla hash para realizar búsquedas rápidas mediante claves y valores. 

using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // Creamos una tabla hash (Diccionario) con claves y nombres
        Dictionary<int, string> tablaHash = new Dictionary<int, string>();

        // Agregamos elementos (Clave, Valor)
        tablaHash.Add(101, "Priscila");
        tablaHash.Add(102, "Brissel");
        tablaHash.Add(103, "Carlos");

        int claveBuscada = 102;

        // Búsqueda eficiente por clave Hash O(1)
        if (tablaHash.ContainsKey(claveBuscada))
        {
            Console.WriteLine("¡Elemento encontrado! Nombre: " + tablaHash[claveBuscada]);
        }
        else
        {
            Console.WriteLine("Elemento no encontrado.");
        }
    }
}
