6.1. Búsqueda Secuencial

¿Qué es la búsqueda secuencial?

La búsqueda secuencial, también conocida como búsqueda lineal, es el algoritmo más sencillo y directo para encontrar un elemento dentro de un conjunto de datos. Consiste en recorrer la estructura de datos elemento por elemento, desde el primer componente hasta el último, comparando cada valor con el objetivo buscado hasta encontrar una coincidencia o llegar al final de la lista.

Cómo funciona (paso a paso)
  1. Se toma el primer elemento de la lista (índice 0) como punto de partida.
  2. Se compara el valor de ese elemento con el dato objetivo que se desea encontrar.
  3. Si coinciden, el algoritmo se detiene y devuelve la posición (índice) actual.
  4. Si no coinciden, el algoritmo avanza automáticamente al siguiente elemento de la lista.
  5. El proceso se repite hasta hallar el elemento o llegar al final del arreglo, indicando en este último caso que el dato no existe.
Ventajas y Desventajas
  • Simplicidad: Es muy fácil de entender, programar e implementar en cualquier lenguaje de código como C#.
  • Independencia del orden: A diferencia de la búsqueda binaria, no requiere que los datos estén previamente ordenados; funciona perfectamente con listas totalmente revueltas.
  • Desventaja principal: Es ineficiente en listas muy grandes, ya que si el elemento está al final o no existe, el programa tiene que revisar absolutamente todos los datos (baja velocidad).
Complejidad algorítmica
  • Mejor caso: O(1) — el elemento buscado está justo en la primera posición.
  • Caso promedio y Peor caso: O(n) — se deben recorrer los n elementos de la lista.
  • Espacio: O(1) — solo requiere memoria auxiliar básica para los contadores y variables de control.
