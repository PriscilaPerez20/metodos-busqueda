6.2. Búsqueda Binaria

¿Qué es la búsqueda binaria?

La búsqueda binaria es un algoritmo altamente eficiente diseñado para encontrar un elemento dentro de una lista o arreglo que se encuentre previamente ordenado. En lugar de revisar los datos uno por uno, el algoritmo funciona dividiendo repetidamente el espacio de búsqueda a la mitad, descartando el 50% de los elementos en cada paso. Por ejemplo, es el mismo principio que usamos al buscar una palabra en un diccionario impreso o un nombre en una guía telefónica.

Cómo funciona (paso a paso)
  1. Definir dos apuntadores: Inicio (primer elemento de la lista) y Fin (último elemento).
  2. Calcular el índice del elemento central (la mitad exacta entre el inicio y el fin).
  3. Comparar el valor del elemento objetivo con el elemento que está justo en el centro.
  4. Si coinciden, el algoritmo ha encontrado el dato y devuelve su posición (índice).
  5. Si el objetivo es menor que el centro, se descarta toda la mitad derecha ajustando el apuntador de Fin a la izquierda del centro.
  6. Si el objetivo es mayor que el centro, se descarta toda la mitad izquierda ajustando el apuntador de Inicio a la derecha del centro.
  7. El ciclo se repite hasta encontrar el elemento o hasta que los apuntadores se crucen, lo que indica que el dato no existe en la lista.
Ventajas y Desventajas
  • Alta velocidad: Es sumamente rápida, incluso con millones de datos (ideal para bases de datos y catálogos masivos).
  • Menor cantidad de comparaciones: Reduce drásticamente el esfuerzo de procesamiento de la computadora en comparación con la búsqueda lineal.
  • Requisito estricto (Desventaja): La lista debe estar ordenada obligatoriamente antes de aplicar el algoritmo; si los datos están revueltos, no funcionará correctamente.
Complejidad algorítmica
  • Mejor caso: O(1) — el elemento buscado se encuentra exactamente en la posición central a la primera comparación.
  • Caso promedio y Peor caso: O(log n) — el espacio de búsqueda se reduce a la mitad en cada iteración.
  • Espacio: O(1) en su versión iterativa, utilizando solo variables auxiliares básicas.
